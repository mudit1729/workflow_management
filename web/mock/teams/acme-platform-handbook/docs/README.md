# Platform handbook

How the platform team builds, ships and runs things. It lives next to the services, so a change to a service and a change to its runbook go in one pull request.

> [!TIP]
> New here? Read [[getting-started]] first. On call tonight? Go straight to [[runbooks]].

## What is here

| Section             | Read it when                                    |
| ------------------- | ----------------------------------------------- |
| [[getting-started]] | You joined this week, or you have a new laptop. |
| [[runbooks]]        | An alert fired, or a key is about to expire.    |
| [[architecture]]    | You need to know which service owns what.       |

## How the handbook is kept

- One page, one subject. A page that needs its own table of contents should be split.
- Every runbook names an owner and the date someone last walked through it.
- Something wrong or out of date? Open the page on GitHub and send a pull request.

## Who to ask

The handbook is owned by @ana and @li. For anything urgent, page the platform on-call, not the owners.
